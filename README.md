# SOFOF TECH IT FARM — Modern Enterprise Web Platform

Next-generation, responsive web application for **SOFOF TECH IT FARM**, crafted with modern high-performance design, rich micro-interactions, authentic media, and multi-page architecture inspired by premier agency standards.

## 🚀 Live Demo
- **GitHub Pages**: [https://mejbaurbahar.github.io/sofoftech-modern/](https://mejbaurbahar.github.io/sofoftech-modern/)

## 🌐 Site Structure
- **Home** (`index.html`): High-converting hero with real Dhaka engineering team, animated stats counter, interactive services grid, tech stack filter, client showcase, verified case studies, authentic culture photo strip, live LinkedIn job circulars, and contact CTA.
- **About Us** (`about.html`): Distinct cloud architecture strategy planning visual, company history, leadership, vision, and core engineering principles.
- **Services** (`services.html`): Detailed service breakdowns across Full-Stack Web Development, Native & Cross-Platform Mobile, Enterprise AI & ML Engineering, UI/UX Product Design, Cloud Architecture & DevOps, and Software Quality Assurance (QA).
- **Projects / Case Studies** (`case-studies.html`): Qatarat Mecca Logistics, Salam Pay Biometric POS, ProWhats Automation, Digital Twin AI, Smart Execution Provisioning, and AI Voice Agent.
- **The Sofof Model** (`the-model.html`): Dedicated Engineering Pods, Milestone-Driven Delivery, and Hybrid Partnership engagement frameworks.
- **Inside SOFOF** (`inside-sofof.html`): 100% authentic team photo gallery featuring the Full Engineering Team, Software QA Pod, and Annual Tours across Cox's Bazar and Sitakundo with interactive fullscreen lightbox viewer (`1 / 5`).
- **Contact** (`contact.html`): Interactive inquiry form with direct WhatsApp click-to-chat integration, Dhaka HQ location details, and active consultation calendar.

## 🛠️ Tech Stack
- **HTML5 & Vanilla JavaScript**: Clean, semantic markup with 0 external framework overhead.
- **Tailwind CSS (Utility Styling)**: Responsive layouts, modern typography, glassmorphism, and color schemes.
- **Lucide & Vector SVGs**: Crisp vector icon assets and official social media branding.
- **Modern Animations**: Scroll reveal triggers, smooth counters, and responsive navigation drawers.
